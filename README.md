# javascript-lotto-precourse

사용자의 입력을 기반으로 로또 구매, 발행, 당첨 결과 계산, 수익률 산출까지 수행하는 콘솔 기반 로또 발매기 프로젝트입니다.

## 기능 요구사항 요약

- 로또 구매 금액 입력

  - 1,000원 단위로 입력
  - 1,000원 단위로 나누어 떨어지지 않는 경우 예외 처리

- 당첨 번호 입력

  - 쉼표 기준으로 구분
  - 0 ~ 45 중 6개 숫자 입력

- 보너스 번호 입력

  - 0 ~ 45 중 1개 숫자 입력

- 로또 수량 및 번호 출력

  - 로또 번호는 오름차순 정렬

- 당첨 내역 출력

  - 1,2,3,4,5등 일치 항목 중 몇개 일치했는지 출력

- 수익률 출력

  - 소수점 둘째 자리에서 반올림

- 예외 메시지 출력

</br>

## 기능 체크리스트

#### 로또 구입

- [ ] 구입 금액 입력
- [ ] 구입 금액에 맞게 로또 개수 발행
- [ ] 1,000 단위로 나누어 떨어져야 함

#### 로또 발행

- [ ] 한 장당 1 ~ 45 사이 중복되지 않는 6개 번호 랜덤 발행
- [ ] 번호 오름차순 정렬
- [ ] 구매 개수 및 로또 번호 목록 출력

#### 당첨 번호 및 보너스 입력

- [ ] 당첨 번호를 쉼표를 구분하여 입력
- [ ] 입력된 번호는 6개
- [ ] 각 번호는 1 ~ 45 사이의 정수
- [ ] 당첨 번호 이외 보너스 번호 입력

#### 당첨 결과 계산

- [ ] 구매한 모든 로또 번호와 당첨 번호 비교
- [ ] 일치 개수 + 보너스 번호 포함 여부 계산
- [ ] 일치 개수와 보너스 일치 여부 기준으로 등수 판별
- [ ] 등수 갯수 집계
- [ ] 총 상금 합산
- [ ] 수익률 계산

## 예외 체크리스트

#### 구입 금액 관련 예외

- [ ] 구입 금액이 숫자가 아님
- [ ] 음수 또는 0원
- [ ] 1,000원 단위가 아님
- [ ] 소수점 입력
- [ ] 입력이 공백 or 비어있을 때

#### 당첨 번호 입력 관련 예외

- [ ] 쉼표로 구분되지 않은 입력 -> '1 2 3 4 5 6'
- [ ] 숫자 외 문자 포함
- [ ] 숫자 6개 미만
- [ ] 숫자 6개 초과
- [ ] 중복된 번호 존재
- [ ] 숫자 범위 초과 (1 미만 or 45 초과)
- [ ] 공백 또는 빈 입력

#### 보너스 번호 입력 관련 예외

- [ ] 숫자가 아닌 입력
- [ ] 범위 초과 (1 미만 or 45 초과)
- [ ] 당첨 번호와 중복
- [ ] 공백 또는 빈 입력
